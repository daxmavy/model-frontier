The Model Frontier

Which language models buy you the most capability per dollar. Cost is measured holistically where possible: the total spend to run a whole benchmark, which counts verbosity and reasoning tokens rather than the headline token price. Each reasoning effort level is its own mark.

Reading the chart

A model on the dashed line is Pareto-optimal: nothing cheaper scores higher, and nothing higher-scoring is cheaper. Models below the line are dominated, which means some other model beats them on both axes at once. Marks are sized by reasoning effort, so a model run harder appears as a larger mark further right.

Where the numbers come from

Caveats

  • Benchmark scores measure benchmark performance. They are a proxy for usefulness, not a measurement of it.
  • The cost of running the index is a single measurement per model, not an average over repeated runs, so small differences are noise.
  • List prices ignore batch discounts, caching, and negotiated rates. Cached input in particular can move real costs a long way.
  • Some scores are estimated rather than measured. Turn off Estimated scores to exclude them.
  • Models Artificial Analysis has retired are left out entirely.
